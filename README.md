# Project: Long_Night
스토리와 뱀서 라이크 장르를 결합한 게임, 프로젝트: 장야


## 프로젝트 소개
**프로젝트: 장야(Long_Night)**는 스토리 중심의 진행과 뱀서 라이크(Vampire Survivors-like) 장르를 지향하는 게임입니다.

게임의 배경인 에트리아에는 인간보다 대부분의 면에서 우월한 성능을 갖춘 존재인 '비스크돌'이 존재합니다.

비스크돌은 상당히 고가에 거래되지만, 소유자는 자신의 뜻에 따라 비스크돌을 사용할 수 있습니다.

비스크돌 두 체를 소유한 플레이어는 평화로운 일상을 보내고 있었습니다.

그러던 어느 날, 분노로 가득 찬 기괴한 적이 플레이어의 저택에 침입합니다.

플레이어는 동료들을 모아 사건의 정체를 파악하기로 결심하고, 이야기는 본격적으로 전개됩니다.

### 주요 특징
1. 스토리 중심 진행: 에트리아를 배경으로 펼쳐지는 이야기와 캐릭터들의 서사

2. 뱀서 라이크 전투: 다양한 적과 전투하며 진행하는 게임 플레이

3. 캐릭터 중심 구성: 각 캐릭터의 개성과 이야기를 바탕으로 한 전투 및 연출

※ 실제 구현 및 개발 진행 상황에 따라 내용을 수정할 예정입니다.
